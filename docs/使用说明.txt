Excel 名称清理工具 v1.4.0
开发者：Opera-Jin（AI 辅助开发）
========================================

一个单文件、免安装、不联网的绿色小工具。
专治「反复复制粘贴工作表 → 名称管理器里堆积几十万个无效名称 → 文件越用越大、
打开越来越慢」的老毛病。

只删名称，不动数据、不动公式、不动格式。

一、为什么会有几十万个无效名称
----------------------------------------
在 Excel / WPS 里复制工作表时，原表上的「定义名称」（含打印区域、打印标题、
筛选范围）会跟着复制一份；删表、改表名之后，这些名称就变成指向 #REF! 的
僵尸名称。Excel 每次打开文件都要把它们全部读一遍，于是越开越慢、越存越大。
本工具直接改写文件内部的名称表，把这些僵尸名称整批摘掉。


二、怎么用
----------------------------------------
1. 双击 Excel名称清理工具.exe（无需安装，也不会写注册表）。
2. 把 Excel / WPS 文件拖进窗口，或点「添加文件」「添加文件夹」。
   支持一次拖多个，也支持整个文件夹（可勾选是否递归子目录）。
   注意：如果拖进去没反应，通常是本工具以「管理员身份」运行导致的 ——
   Windows 会阻止低权限的资源管理器向高权限窗口拖放文件。
   此时请改用「添加文件 / 添加文件夹」按钮，功能完全一样。

   加进来后会立刻统计并显示每个文件「现有多少个名称」；

   加错了想撤掉某个文件？在列表里点一下选中它（按住 Ctrl 或 Shift 可多选），
   然后点「移除选中」，或者直接按 Delete 键。也可以右键点那一行，选
   「移除选中」或「打开文件所在位置」先确认是不是这个文件。
   移除只是把它从列表里拿掉，**不会删除或改动磁盘上的任何文件**；
   移除之后想重新加回来，再拖一次就行。

   表格的列可以随意调整（和 Windows 资源管理器一样）：
     · 点表头：按这一列排序，再点一次反向；表头会出现 ▲ / ▼
     · 拖动两列之间的竖线：调整列宽，松手后不会弹回去
     · 按住表头左右拖：把这一列挪到别的位置
     · 右键表头：将列调整为合适的大小 / 恢复默认列宽与顺序 /
       勾选要显示的列（文件名、大小、名称、耗时、结果、时间）
   这些调整会自动记住，下次打开还是你排好的样子。
   如果拖进来的是 txt / pdf 之类不支持的文件，会弹窗直接告诉你哪些被跳过。
3. 按需调整下面四个选项，然后点「开始清理」。
4. 处理时底部会实时刷新：进度条、当前文件与所处阶段（如「删除名称 28万/40万」）、
   已用时、预计剩余、已删除名称数、已减少体积。
5. 处理完每一行会标出：删了多少名称、花了多少秒（精确到 0.1 秒）、
   这次操作的时间（精确到分钟）。双击某一行可以看完整详情
   （删了什么、留了什么、为什么留）。
6. 想回看以前跑过的记录，点右上角「历史记录」：按时间倒序列出每一次处理，
   双击任意一条可以看当时的详情。


三、四个选项
----------------------------------------
[√] 保留打印区域 / 打印标题名称
    这两类名称属于「打印设置」，不是数据。默认保留，避免打印范围被重置。
    想要清理得更彻底（比如文件要归档、不再打印），可以取消勾选。

[√] 断开外部链接
    外部链接是指公式引用了别的 Excel 文件（如 =[预算表.xlsx]Sheet1!A1）。
    勾选后的效果与 Excel 里「数据 → 查询和连接 → 编辑链接 → 断开链接」完全一致：
      · 引用外链的公式会被替换成它此刻的数值（数字、文本、日期都一样）
      · 不会出现 #REF!，不会出现 #NAME?
      · 外部链接记录与缓存一并清除，文件体积明显变小
    代价：这些单元格从此变成固定值，不再随源文件更新。
    勾选后会先弹一次确认；已勾选「自动备份」时随时可以用 .bak 还原。

[√] 处理前自动备份（.bak）
    在原文件同目录先复制一份「原文件名.bak」，再改原文件。
    · 处理成功且没有报错 → 备份自动删除，不留垃圾文件
    · 处理失败或中途出错 → 备份保留，把 .bak 改名回原扩展名即可还原

[√] 后台模式：降低 CPU 占用
    把本工具和它的处理线程降到「低于正常」优先级，并在处理过程中主动让出 CPU。
    这样你在清理大文件的同时照常用 Excel / WPS、看视频、开会，不会卡顿。
    清理期间可以直接把窗口最小化，任务会在后台继续跑完。


四、安全边界（重要）
----------------------------------------
· 只删除「没有被任何公式引用」的名称。
  被公式、数据验证下拉、条件格式、图表、数据透视表引用的名称，一律保留，
  不会出现 #NAME? 错误。
· 完全不碰单元格、样式、图表、图片、合并单元格、宏（.xlsm 的 VBA 原样保留）。
· 不做重新计算，不打开 Excel/WPS，不依赖任何 Office 组件。
· 处理前自动备份；写入采用「临时文件 + 原子替换」，中途断电也不会写坏原文件。
· 文件正被 Excel / WPS 打开时会直接跳过并提示，不会强行改写。


五、支持的文件格式
----------------------------------------
.xlsx  .xlsm  .xltx  .xltm   —— Excel 2007 及以上（含启用宏）
.xls                         —— Excel 97-2003
.et                          —— WPS 表格（新版与老版都支持）
.xlsb                        —— 支持，但会先转成 .xlsx（见下）

.xls 与老版 .et 是二进制格式，本工具会直接重写其内部的名称表，
不经过 Excel/WPS 转换，因此不会丢失任何格式或宏。
注意：旧版格式暂不支持「断开外部链接」这一项。

关于 .xlsb：
  .xlsb 内部是微软的二进制格式，无法安全地直接改写，所以采用与老版本相同的
  做法 —— 调用本机已安装的 Excel（或新版 WPS）把它「另存为 .xlsx」，
  再对 .xlsx 做清理，最后**直接留下 .xlsx 文件**。

    · 原 .xlsb 文件完全不动
    · 生成的新文件与它同目录同名，只把扩展名换成 .xlsx
      （如 报表.xlsb → 报表.xlsx；若已存在则依次为 报表(1).xlsx）
    · 这一步需要本机装有 Excel 或新版 WPS；两者都没有时会明确提示
    · 转换过程中会自动关闭提示框，不会弹窗打断你

    └─ history.jsonl               结构化历史记录（界面「历史记录」读的就是它）

七、常见问题
----------------------------------------
Q：杀毒软件报毒 / 提示未知发布者？
A：这是 PyInstaller 打包的绿色程序常见误报，本工具不联网、不写注册表、
   不驻留后台。可加入信任，或改用源码自行打包。
   首次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。

Q：提示「文件正被占用」？
A：该文件正在 Excel / WPS 里打开。关闭后重试即可（工具不会强行改写）。

Q：断开外链后，单元格为什么变成数字了？
A：这是刻意的，与 Excel 手动「断开链接」行为一致 —— 保留当时算出来的值，
   而不是留一个 #REF!。如果你还需要它随源文件更新，请用 .bak 还原，
   然后取消「断开外部链接」重新处理。

Q：名称删了很多，但文件体积没小多少？
A：名称本身占的空间有限，真正占体积的是图片、图表、样式、缓存。
   本工具的目标是「打开变快、名称管理器变干净」，体积下降是附带效果。
   勾选「断开外部链接」通常能再省一截。

Q：处理 .xlsb 时提示找不到 Excel / WPS？
A：.xlsb 是微软的二进制格式，本工具靠本机的 Excel（或新版 WPS）把它另存为
   .xlsx 后再清理。如果这台机器两者都没装，请在有 Office 的电脑上先另存为
   .xlsx，再拿过来处理。

Q：会不会把我正常的名称删掉？
A：只要它被公式/验证/条件格式/图表引用，就会被保留。
   处理详情里会列出「保留了哪些、为什么保留」，可以逐条核对。


八、性能参考（本机实测）
----------------------------------------
40 万个名称的 .xlsx：约 4 秒，1.1 MB → 69 KB
464 个名称 + 31 个工作表：约 0.1 秒
处理速度与文件大小、名称数量成正比，与是否安装 Office 无关。
